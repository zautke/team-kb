# Implementation log — Phase 1/2 portable deployment kit (2026-08-16)

## Delivered

- `deploy/otel/` — self-contained Docker stack: Aspire dashboard 13.0,
  collector contrib 0.158.0, `TeamKb.OtlpBridge` (built from source by
  compose), optional Cosmos emulator profile. All ports/images/credentials in
  `.env` (SSoT, gitignored; `.env.example` committed). Ports all >10000.
- `deploy/otel/collector/config.yaml` — full-fidelity pipelines → bridge + Aspire.
- `deploy/otel/collector/config-azure.yaml` — adds the curated pipeline:
  redaction allowlist (mirrors `Telemetry.cs`) → 1 KB truncate → D3
  tail-sampling starter set → `azuremonitor` exporter.
- `deploy/otel/otel-stack.sh` — up/down/status/logs/validate/smoke; `smoke`
  sends a synthetic OTLP/JSON span and asserts it lands in the bridge sink.
- `src/TeamKb.OtlpBridge/` — the D0 gap-closer: OTLP/JSON → Cosmos documents
  (partition `/sessionId`, raw span embedded, full fidelity) with a JSONL
  file-sink fallback when no Cosmos is configured. Multi-stage Dockerfile.
  Standalone project — NOT added to TeamKb.sln (no build-host dotnet dependency;
  compose builds it).
- `docs/research/otel-agentic-csharp/09-local-deployment.md` — detailed
  machine-agnostic runbook (quick start, app wiring, Cosmos options, Azure
  variant, troubleshooting, limitations).
